# Cyber Protocol — Game Vision

## Game Concept

- **Title:** Cyber Protocol
- **Genre:** Cinematic Cyber Intelligence Action RPG (A-RPG) & Tactical Terminal Simulator
- **Platform:** Android-first, designed around a mobile tactical interface

## 1. Visual & Art Direction

- Cinematic, semi-realistic, anime-inspired cyber intelligence aesthetic.
- Premium AAA mobile-game interface quality.
- **Color palette:**
  - Obsidian Black — `#090A0E`
  - Charcoal — `#15171D`
  - Crimson Red — `#D62839` (primary emphasis and alerts)
  - Blood Red — `#8E1525`
  - Metallic Silver — `#858A96`
  - Soft White — `#F1F1F3`
- Atmospheric, dark futuristic intelligence-headquarters environments.
- Sophisticated geometric shapes, precise edges, clean silhouettes, and controlled crimson illumination.

## 2. Core Narrative & Setting

- **Organization:** A.E.G.I.S. — Advanced Espionage & Global Intelligence Service.
- **Headquarters:** Manila.
- **Campaign 01:** The Recruitment.
- **Chapter 001:** First Contact.
- The player begins as an ordinary civilian who receives a mysterious encrypted recruitment message and is drawn into clandestine intelligence operations.

### Main Characters

- **Freya Knox:** The primary human mentor. Brilliant, mischievous, energetic, and deeply competent.
- **NEXUS:** A text-based AI communication system. It uses a neutral silhouette icon and does not have a face portrait.

## 3. Gameplay & Mechanics

### Investigation and Intelligence Work

- Hacknet-inspired investigation.
- Immersive terminal interactions.
- Virtual file system.
- Dossier examination.
- Evidence analysis.

### Python Learning From Zero

- Designed for absolute beginners with no prior programming knowledge.
- Programming concepts are integrated into solving fictional intelligence cases.
- Learning and applying code progressively unlocks system permissions and operational capabilities.

### In-Game Terminal

- Functional terminal with Linux-like commands, including `pwd`, `ls`, `cd`, and `cat`.
- Local Python 3 execution environment.

### RUN and SUBMIT

- **RUN:** Executes the player's script for experimentation, testing, and debugging. It displays execution output without judging official mission completion.
- **SUBMIT:** Evaluates the player's work against the official mission criteria.

### App Hub

A smartphone-style operational interface in the upper-right area provides access to:

- Secure Messenger
- Terminal
- Intranet Browser
- Dossier
- Analysis

## 4. Target Experience

Blend a high-stakes cyber-thriller narrative with accessible, progressively challenging coding tasks. The result should feel like a premium mobile RPG and intelligence simulator, not a collection of disconnected programming exercises.

## Design Intent

This document captures the visual identity, premise, major characters, core interaction concepts, and intended player experience. It is a high-level vision reference, not a complete implementation specification. Detailed story structure, mission design, RPG systems, learning progression, interface flows, and technical architecture remain to be designed.
